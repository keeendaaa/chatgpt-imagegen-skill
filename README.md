# ChatGPT Image Generation — скилл и плагин OpenCode V2

Генерация и редактирование PNG через подписку ChatGPT. Комплект включает скилл, локальную V2-адаптацию плагина, исходники, зависимости и тесты. OpenAI API key не используется; каждый реальный вызов расходует квоту подписки.

## Требования

- OpenCode V2 с поддержкой plugin tools и integration connections. Локальная адаптация ранее проверялась на v2.0.29; совместимость со всеми последующими версиями не гарантируется.
- Bun для установки зависимостей и запуска тестов; Git.
- Аккаунт ChatGPT с доступом и доступной квотой генерации изображений.

## Установка

Клонируйте репозиторий в постоянный каталог (его нельзя удалять после установки):

```sh
git clone https://github.com/keeendaaa/chatgpt-imagegen-skill.git
cd chatgpt-imagegen-skill
bun install --frozen-lockfile
bun run test
pwd
```

Добавьте **абсолютный путь, выведенный `pwd`**, в массив `plugins` вашего `~/.config/opencode/opencode.json` или `opencode.jsonc` (либо в проектную конфигурацию). Сохраните остальные настройки и существующие плагины:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["/ABSOLUTE/PATH/chatgpt-imagegen-skill"]
}
```

Пакет экспортирует `v2.ts`, а не исходную V1-точку входа. Дополнительный loader не нужен. Не подключайте одновременно другую копию плагина с ID `local.gpt-imagegen.v2`.

Установите скилл из корня клона (если такой файл уже есть, сначала сравните и сохраните свою версию):

```sh
mkdir -p ~/.config/opencode/skills/chatgpt-imagegen
cp -i SKILL.md ~/.config/opencode/skills/chatgpt-imagegen/SKILL.md
```

В OpenCode выполните `/connect`, выберите OpenAI и войдите через ChatGPT OAuth. Не вставляйте API key или токены в файлы проекта. При необходимости выполните `/reload`.

## Проверка и использование

`opencode plugin list` должен показывать `local.gpt-imagegen.v2` без ошибки загрузки. Проверьте доступность инструмента `gpt_imagegen` в сессии; проектные разрешения могут ограничивать его.

Пример запроса, **который уже расходует квоту**:

> Сгенерируй через gpt_imagegen квадратную иллюстрацию лисы у домика в лесу, без текста. Размер 1254x1254, сохрани в output/fox.png.

Для редактирования укажите пути к исходным изображениям (до пяти) и что нужно изменить. Для прозрачного фона попросите `background: transparent`. Размеры и параметры перечислены в [SKILL.md](SKILL.md).

## Ограничения и тесты

`bun run test` использует подменённые сетевые ответы и не вызывает реальную генерацию. Проверяются обработка изображений, размеры, транспорт, регистрация V2-инструмента, OAuth, разрешения, путь сессии и версионирование файлов. Это не заменяет проверку загрузки плагина на вашей версии OpenCode и реальный вызов сервиса.

Текстовая генерация ранее проверялась локально на OpenCode v2.0.29. Редактирование и прозрачность реализованы, но в этом комплекте не заявляются как проверенные реальными запросами. Сервер может менять размеры на пиксель; точные произвольные размеры не поддерживаются. Защита от перезаписи best-effort, поэтому не запускайте параллельные вызовы с одинаковым путём вывода.

Используется endpoint ChatGPT Codex Images, который может измениться независимо от плагина. Нет автоматического перехода на платные API. При ошибке OAuth проверьте `/connect`, при исчерпании квоты дождитесь её восстановления. При отсутствии инструмента проверьте состояние плагина и разрешения проекта.
